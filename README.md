## 计算范围与限制

- 保留原始 HTML 的计算公式和制剂设置；发布整理不等于临床验证。
- 含氮量预设按制剂标示 9.24 g/L 计算，使用者必须核实实际制剂。
- 备用配液按 24 小时量 × 备用小时数 / 24 计算，不把额外备液计入 24 小时摄入。
- 制剂浓度可修改，但原有组分名称仍使用固定规格标签，修改规格时需特别核对。
- 额外液体和其他添加液没有完整的营养及电解质成分建模，结果不代表全部来源的总摄入。
- 长嘱0.9%氯化钠按实际24小时输入量 × 0.154 mmol/mL计钠，与甘油磷酸钠所带钠一起从目标钠量扣除，再换算浓钠用量。该体积必须已包含在“长嘱液体、奶量”中，不重复扣体积。无盐水时须填0。
- 钠合计只包括TPN和录入的长嘱盐水，未包含药物本身、奶液等其他钠来源。长嘱葡萄糖只扣体积，不计入GIR或热卡。盐水与甘油磷酸钠合计已超目标时，浓钠为0并保留超量警告（含复制内容）。
- 盐水换算依据：[0.9% Sodium Chloride Injection说明书](https://dailymed.nlm.nih.gov/dailymed/fda/fdaDrugXsl.cfm?setid=d98bf9f7-30ec-4927-a577-cabad192cb18)，钠154 mEq/L（对Na⁺等于154 mmol/L）。
- 原有目标钠量无法满足时会显示警告，必须复核，不能仅凭绿色结果认定处方有效。
